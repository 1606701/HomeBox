## D1 部署架构 = aarch64（64 位）

| 项 | 结论 |
|---|---|
| 板子架构 | **aarch64（用户已确认）** |
| Node 版本 | 推荐 **Node 22.x LTS**（`node:sqlite` 可用的最低现实选择是 22.13）；Node 24 同样可跑 |
| `engines` | `>=22.13`，**不再为 armv7 保留兼容分支**，不写 `<25` 上限 |
| 原生模块 | 不需要。无 node-gyp、无板端编译，安装 = 官方 arm64 tarball 或 NodeSource |
| 已知现象 | Node 22 上 `require('node:sqlite')` 会打印一行 `ExperimentalWarning`，属正常。`npm start` 用 `NODE_NO_WARNINGS=1` 屏蔽，启动日志只留自己的输出 |

影响：`ARCHITECTURE.md` §1 里「32 位锁 22.x」的约束解除，R7 风险降级为「锁 22/24 两代均可」。

## D2 单币种（不做多币种）

| 项 | 结论 |
|---|---|
| 支持币种 | **仅人民币（CNY）** |
| `items.currency` 列 | **不建**。架构文档 §6 的 `currency TEXT` 作废 |
| `settings.base_currency` | 固定 `'CNY'`，不暴露给用户，只供导出文件自描述 |
| 前端 | 录入与概览都不出现币种选择 |
| 收益 | 金额聚合无分组、少一个必然填错的下拉、P2 省约 0.5 天 |
| 将来扩展 | 加 `currency TEXT NOT NULL DEFAULT 'CNY'` + 按币种分组，是纯增量迁移，不返工 |

金额规则不变：`price_cents INTEGER NULL`，单件小计 `price_cents * qty`，两个口径（在库 / 累计购入）并列显示。

## D3 备份：三层，SMB/NAS 为「有则增强、无则指导」

用户原话：有 NAS 就给地址和访问权限自动备份；没有就在邮件里通知备份怎么操作。

**必须先说清的技术现实：Node 进程不做 mount。** 挂载 SMB 需要 root + `cifs-utils`，把 `sudo mount` 的能力交给一个家庭收纳 Web 服务，等于自建提权入口——这与「局域网、无 HTTPS、防家人误操作」的威胁模型直接冲突。所以拆成三层，权限边界清楚：

| 层 | 触发条件 | 动作 | 用户要做的事 |
|---|---|---|---|
| **L0 本地** | 每天 03:00（随调度器） | `export` 到 `data/backup/homebox-YYYYMMDD.json`，保留 7 份 | 无 |
| **L1 外部目录** | 已配置 `settings.backup_dir` 且探针可写 | 复制 L0 结果到该目录，保留 30 份 | 一次性：把 NAS 挂到 `/mnt/nas`（设置页给可复制命令） |
| **L2 无外部** | 每日摘要邮件 | 邮件末尾附「三步备份」+ 当前备份状态（上次成功时间 / 份数 / 占用） | 无 |

设置页要提供（**是 UI，不是文档**）：

1. 「备份位置」输入框 + **「检测可写」按钮**：写一个探针文件再删掉，返回成功/权限/路径不存在三种明确结果。
2. 可一键复制的挂载模板：
   ```
   //192.168.1.100/home /mnt/nas cifs credentials=/etc/nas.cred,uid=1000,iocharset=utf8,vers=3.0,nofail 0 0
   sudo mount -a
   ```
   （`/etc/nas.cred` 内容两行：`username=` / `password=`，`chmod 600`。这段同时出现在邮件里。）
3. 备份状态卡：上次成功、连续失败次数、占用空间。

**明确不做**：应用内执行 `mount`、存 SMB 账号密码、要求 sudo 提权。这三件都会把「拷过去 `node server.js` 就跑」变成「装完还要配系统」。
若用户愿意接受一次系统配置，L1 就是「自动备份」——挂载由 systemd/fstab 保证，应用只负责往已挂载目录里写，失败自动降级为 L2 邮件告知。

## D4 拍照识别默认免费档

| 项 | 结论 |
|---|---|
| 默认模型 | 智谱 **GLM-4.6V-Flash（永久免费档）** |
| 可切换 | 设置页可改 provider / baseURL / model / Key，付费档（GLM-4.6V、qwen3-vl、豆包）随时可换 |
| 降级链 | 未配 Key → `/api/vision/recognize` 返回 404 → 前端**不渲染**拍照按钮；超时/失败 → 200 + 一行灰字，表单照常可存 |
| 代码约束 | `lib/vision.js` 必须把「**提示词**」「**白名单收敛**」「**JSON 校验**」三件事拆成独立函数——用户明说效果不好会再来改，换模型/调提示词不能动其他两件 |
