只备份在这台机器的卡上，卡坏了会一起没。

没有 NAS 怎么备份
  1. 在 NAS（或带 USB 的路由器）上开一个共享文件夹，记下地址、账号、密码。
  2. 在香橙派上建 /etc/nas.cred，写 username= 和 password= 两行， 再把下面这一行加进 /etc/fstab，执行一次 sudo mount -a。
  3. 回来把挂载后的路径（比如 /mnt/nas）填到上面，点「检测可写」。

//192.168.1.100/home /mnt/nas cifs credentials=/etc/nas.cred,uid=1000,iocharset=utf8,vers=3.0,nofail 0 0
